# Site operations

Problems & Suggestions is under League. Site Log appears there only in admin mode; navigation to it outside admin mode returns to Home, and exiting admin mode closes the log. Feedback is stored in Netlify Database. Site Log also requires the existing admin password on the server, independent of the browser's admin mode. Admins can paginate logs and feedback, filter by log type, review 30-day per-team opens/actions, and mark reports open, reviewing or resolved.

The additive migration is applied by Netlify during deployment. Existing migrations are unchanged. Opens are recorded on each page load and after returning from at least 30 minutes of inactivity. Page navigation, team/player details, lineup panels, button interactions and selector changes are tracked. Attribution uses My Team and a random persistent device ID; it is self-reported, not authenticated manager identity. No form input, subscription credentials or admin passwords are logged. An unselected team is Unassigned. Offline use, browser storage restrictions, blocking and failed analytics requests can create gaps. Tracking starts at this release and cannot recover earlier history.

Successful browser writes to announcements, home settings, trade listings, manual notification queue and parlays create change records, with bounded content snapshots when available. These are client observations, not a tamper-proof audit trail. The deploy event function records successful deployments; release notes describe this release. Direct database edits and external content writers require their own server-side audit hook and are outside browser coverage.

The nightly Netlify trade digest records confirmed sender results. All other push outcomes are reported by the existing Supabase notify sender to the authenticated Netlify activity endpoint. The updated `supabase/functions/notify/index.ts` must also be deployed to the existing Supabase function for those reports to appear; a Netlify deployment does not deploy Supabase functions. The existing webhook routes must continue pointing to that sender. Queue acceptance and delivery outcomes are explicitly separate. Delivery reports include title, body, targeted teams and aggregate sent/failed/expired counts, never subscription endpoints or keys. Sent means the push service accepted a notification, not that a manager read it. Logging failure after a send does not trigger another push.

Lineup recommendations use the current weekly projections and roster. They fill the app's standard nine slots using an exact assignment algorithm and never reuse a player. Missing projections, IR players, bye players and unavailable injury statuses are excluded. Ceiling mode needs at least three recorded finalized games and estimates each player's ceiling as projection plus 1.28 historical standard deviations. Recommendations are advisory and do not enforce game locks or modify ESPN lineups. Partial lineups and missing data are shown explicitly.

Elimination numbers describe the combined chasing-team losses and current cutoff-team wins needed to make the cutoff record unreachable. Ties count as half-wins; matching the cutoff record can still depend on points for. This moving-cutoff indicator is not a full schedule-aware elimination proof; the existing playoff odds retain their separate elimination assessment.

The live weekly parlay shows the latest submission per team and an alive, busted, hit or void status derived from those legs. Admins can save each current leg's result independently, including resetting a mistaken result to pending, or edit pick text and odds through the weekly editor. Older submissions remain in the editor and manager history but do not affect the live status. Casino purchase details have their own editable section and save button at the bottom. Public picks and grades refresh every 10 seconds while the app is visible. Unsaved admin result selections and casino fields are preserved during polling. Pick entry defaults to the owner of the selected My Team; visitors without a selected team must explicitly choose a name.
